# AdeoTEK Neovim configuration

Kickstart-based Neovim configuration, restructured to the standard
lazy.nvim layout. Requires **Neovim >= 0.11** (built with LuaJIT).

## Structure

```
nvim/.config/nvim/
├── init.lua                  # leaders, lazy.nvim bootstrap, core config, plugin import
├── lua/
│   ├── config/
│   │   ├── options.lua       # editor options
│   │   ├── keymaps.lua       # all custom keybindings
│   │   └── autocmds.lua      # yank highlight, terminal buffer keymaps
│   └── plugins/              # one lazy.nvim spec per file
│       ├── blink.lua         # completion (blink.cmp + LuaSnip + friendly-snippets)
│       ├── lsp.lua           # LSP servers (mason-org + lspconfig)
│       ├── conform.lua       # formatting
│       ├── telescope.lua     # fuzzy finder
│       ├── treesitter.lua    # syntax highlighting (main branch)
│       ├── theme.lua         # catppuccin
│       ├── bufferline.lua, lualine.lua, alpha.lua, which-key.lua
│       ├── nvim-tree.lua, toggleterm.lua, gitsigns.lua
│       ├── copilot.lua, kickstart.lua   # AI completion, mini.nvim (ai/surround)
│       └── indent_line.lua
├── Cheatsheet.md             # vim basics + custom bindings
├── lazy-lock.json            # generated lockfile (regenerated by :Lazy sync)
└── stylua.toml               # Lua style for this config
```

Everything is lazy-loaded except UI chrome (theme, bufferline, lualine) and
blink.cmp (must load before LSP attaches to register completion capabilities);
the alpha dashboard loads on `VimEnter`.

## Install & first run

The package is deployed by the dotfiles repo via GNU Stow (`stow nvim`).
First launch bootstraps lazy.nvim automatically, installs all plugins, and
opens the dashboard. Language servers and formatters install on first run
via Mason — check progress with `:Mason` (9 servers + 4 formatters:
lua_ls, ts_ls, html, cssls, csharp_ls, bashls, pyright, ansiblels, taplo +
stylua, black, shfmt, prettierd).

Useful commands:

| Command | Purpose |
|---|---|
| `:Lazy` | plugin manager UI |
| `:Lazy sync` | install/update plugins, regenerate lockfile |
| `:Lazy profile` | startup profiling |
| `:Mason` | LSP/linter/formatter manager |
| `:checkhealth` | environment diagnostics |

## Requirements

- Neovim >= 0.11, git >= 2.19
- `make` + C compiler (fzf-native, treesitter)
- `rg` (ripgrep) for live grep, `fd` recommended for file finding
- Nerd Font (icons in bufferline/lualine/telescope)
- `xclip`/`wl-clipboard` (Linux) or `win32yank` (WSL) for system clipboard

## Keybindings

Leader = `<Space>`. Full custom-binding list:

### Files / search (Telescope)
| Key | Action |
|---|---|
| `<C-p>` / `<leader>ff` | find files (hidden included) |
| `<leader>gf` | git files |
| `<leader>fg` | live grep |
| `<leader>fge` | live grep with args |
| `<leader>fb` | buffers |
| `<leader>fh` / `<leader>vh` | help tags |

### Editor
| Key | Action |
|---|---|
| `<leader>e` | toggle file explorer (nvim-tree) |
| `<leader>w` / `<C-s>` | save |
| `<C-A-s>` | save as |
| `<leader>q` | quit |
| `<leader>h` / `<Esc>` | clear search highlight |
| `<C-z>` | undo (normal + insert) |
| `<C-c>` / `<C-v>` / `<C-x>` | system clipboard copy/paste/cut (all modes) |
| `<leader>fm` | format buffer (conform; LSP fallback) |
| `[d` / `]d` | previous/next diagnostic |

### Windows & buffers
| Key | Action |
|---|---|
| `<C-h/j/k/l>` | move focus left/lower/upper/right window |
| `<leader>bn` / `<leader>bp` | next/previous buffer |
| `<leader>bd` / `<C-q>` | close buffer |
| `<C-PageUp>` / `<C-PageDown>` | next/previous buffer tab |
| `<C-\>` | toggle terminal (toggleterm) |
| `jk` or `<esc>` (in terminal) | exit terminal mode |

### Git (gitsigns)
| Key | Action |
|---|---|
| `<leader>gb` | toggle line blame |
| `<leader>gd` | diff file against index |

### LSP (per buffer, once a server attaches)
| Key | Action |
|---|---|
| `gd` | go to definition |
| `K` | hover |
| `gr` | references |
| `<leader>rn` | rename |
| `<leader>ca` | code action |

### Text objects (mini.nvim)
| Key | Action |
|---|---|
| `sa` / `sd` / `sr` | add/delete/replace surrounding |
| `a` / `i` | around/inside text objects (e.g. `va)`, `ciq`) |
| `aa` / `ii` | around/inside **next** node |

## Completion (blink.cmp)

| Key | Action |
|---|---|
| `<C-Space>` | open menu / show documentation |
| `<CR>` | accept completion |
| `<C-n>` / `<C-p>` | next/previous item |
| `<C-e>` | hide menu |
| `<C-b>` / `<C-f>` | scroll documentation |
| `<C-k>` | toggle signature help |

Ghost-text AI suggestions (copilot.lua) trigger automatically in insert
mode; `<Tab>` accepts.

## Customization

- **Add a plugin:** create `lua/plugins/<name>.lua` returning a lazy.nvim
  spec table. It is imported automatically on next start.
- **Add an LSP server:** add `server_name = {}` to the `servers` table in
  `lua/plugins/lsp.lua`. Mason installs it on next start. Per-server
  settings go in the same table (`vim.lsp.config` format).
- **Add a formatter:** add a `formatters_by_ft` entry in
  `lua/plugins/conform.lua` and add the tool name to the mason
  `tools` list in `lua/plugins/lsp.lua`.
- **Change theme flavour:** edit `flavour` in `lua/plugins/theme.lua`
  (latte, frappe, macchiato, mocha).
- **Local tweaks:** see the repo's local-override conventions
  (`~/.config/nvim` is stowed, so edits here are live immediately).

## Formatting style

Formatters run on demand via `<leader>fm` (nothing formats on save).
